三态规范：
· Active：浅 primary 底 + 左 2px primary 竖条 + 文字 primary 色 + 字重 500；若是 accordion 二级 active，纵向层级线整体变 primary
· Hover：5% 黑底 + 文字升 text-1（disabled 项无 hover）
· Disabled：text-3 灰 + opacity 0.5 + cursor not-allowed + badge 可选标注「M3+」/「登录后」等
