叠卡交互流程
新 reminder 进入
badge +1，轻量 pop 动画
卡片本体不重入场
↓
用户完成/稍后顶层
顶层卡片滑出
下一条升为顶层
badge −1
↓
count → 1
badge 隐藏
叠层幻影消失
回到单卡形态

新 vs 旧 对比

特性 旧（expanded/collapsed/bubble） 新（单卡 + 叠卡）
count = 1 普通气泡，无 badge ReminderCard，无 badge ✓
count = 2 2 张气泡上下排列，expanded 模式 顶层 card + 1 层幻影 + badge「2」
count > 2 折叠为 collapsed bubble + badge 左上角 顶层 card + 多层幻影 + badge 右上角
新 reminder 进入 可能触发整卡 enter 动画 只有 badge pop，卡片本体不重入场
状态转换动画 expanded↔collapsed + TransitionGroup 无，只有 badge 轻量动画
overlay 大小 固定 320×280 或动态复杂计算 贴合单卡 / stack 实际尺寸
